Webfinity. — WEBSITE

Open index.html in a browser to view the website.
Pages: Home, About, Services, Portfolio, Contact.
Built with HTML, CSS, and vanilla JavaScript. No build step is needed.

Interactive features: responsive navigation, hero image slider, FAQ accordion, client-side form validation, dark mode, scroll-to-top, animated counters, and typing animation.

The contact form is a front-end demo and does not send or store messages. Connect a form service to receive submissions.
